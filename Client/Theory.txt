=== Block, inline, inline-block elements === 

Block tag properties === 

1. takes full with of parent
2. always starts from new line
3. can set height, width, margin, padding properties
e.g div, p, h1-h6, section

Inline tag properties

1. takes width as it contains
2. always start with same line
3. cannot set height with margin and padding
e.g. span, input, a, i , b
<span
            style={{
              display: "inline-block",
              border: "1 px solid green",
              height: "200px",
            }}
          ></span>

Inline-Block tag properties

1. mix of black and inline
2. we can make any block elements inline-block element by setting display properties
e.g. input, button

e.g. display:inline-block
